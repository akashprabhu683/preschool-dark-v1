# Luna Stars Preschool 🌙✨

A modern, dark-themed preschool website built using HTML, CSS, and JavaScript. It features a playful interface designed to showcase educational programs, creative activities, parent testimonials, and admission enquiries.

## Live Demo

[Visit Luna Stars Preschool](https://preschool-dark-v1.vercel.app/)

## Features

- **Responsive Design:** Adapts to different screen sizes.
- **Dark-Themed Interface:** A playful, night-sky-inspired visual design.
- **Educational Programs:** Dedicated sections for Playgroup, Nursery, and Kindergarten.
- **Creative Activities:** Showcases arts and crafts, music, STEM, and nature walks.
- **Parent Testimonials:** A dedicated section for parent reviews.
- **Admission Enquiry:** A form for prospective parents.
- **Contact Section:** Displays contact information and location details.

## Tech Stack

- **HTML5** – Website structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – Interactive elements and functionality

## Getting Started

### Prerequisites

A modern web browser and a code editor (such as VS Code).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/akashprabhu683/preschool-dark-v1.git
   ```

2. Navigate to the project directory:

   ```bash
   cd preschool-dark-v1
   ```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in VS Code for local development.

## Website Sections

- **Home:** Introduction to Luna Stars Preschool.
- **About:** Overview of the preschool and its learning environment.
- **Programs:** Educational programs for different age groups.
- **Activities:** Creative and educational experiences.
- **Testimonials:** Parent feedback.
- **Contact:** Contact information and admission enquiries.
